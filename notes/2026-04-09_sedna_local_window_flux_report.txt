Interpretation of the recent Sedna figures
- The original full-length path-pixel plot showed a strong shared pre-1450 hump that was too large to be Sedna.
- Quantitatively, that feature behaves like a common-mode cutout-wide background excursion, not a moving-source packet.
- After the 2 extra cadence cuts and per-trace linear detrending, the local-window plot is much easier to interpret.
- The bottom summed panel is visually suggestive, but it is still only a diagnostic. We have not yet computed the expected Sedna contribution in the same transformed units.

Plan for estimating the expected Sedna curve on the bottom panel
- Goal:
  - compute the expected summed curve in the same units and with the same processing as the observed bottom panel
- Correct forward-model ingredients:
  1. Use Sedna’s ephemeris and detector coordinates for Sector 5 at every kept cadence.
  2. Convert Sedna’s brightness into an expected total TESS count rate.
  3. Project that total source rate through the TESS PRF/PSF into the relevant detector pixels cadence by cadence.
  4. Extract the expected contribution for the same nominal path-pixel set used in the diagnostic plot.
  5. Apply the same cadence mask:
     - automatic ramp mask
     - the 2 manual extra cadence cuts
  6. Apply the same per-pixel transformation:
     - if the displayed trace is linearly detrended, apply the same linear detrend operator to the model trace for that pixel
  7. Use the same crossing-time alignment and the same local-window width.
  8. Bin/sum the model traces on the same 0.5 hour grid used in the bottom panel.
- Important subtlety:
  - the expected curve should not be a naive total-flux estimate
  - it must be passed through the same plotting operator as the observed traces, or the comparison will be misleading
- Practical first pass:
  - compute a family of curves for a small bracket of plausible Sedna TESS-band magnitudes rather than pretending the Tmag is exactly known
  - for example: T = V, V - 0.3, V - 0.5
- Deliverable for the next pass:
  - an observed bottom summed curve with one or more overplotted expected Sedna model curves in the same units

Current caution
- Do not interpret the present summed bottom panel as a flux recovery yet.
- The next trustworthy step is the matched forward-model curve, not another purely qualitative plot.
